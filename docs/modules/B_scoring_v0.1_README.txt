3. 입출력
======================================================================
  입력  code(str), obs_date(date/문자열), value(float/Decimal/NaN)
        - DB numeric(Decimal), 문자열 날짜도 처리
        - 아래 경우 ValueError 발생 (조용히 계산하지 않음 → run.py에서 실패로 기록해 주세요)
          · code/obs_date/value 컬럼 없음
          · 5개 지표 중 하나라도 없거나, 값이 모두 비어 있음(전부 NaN)
          · 같은 (code, obs_date) 중복 (5개 지표 안에서)
          · 값에 무한대(inf)
        - 5개 지표 외의 코드는 무시
        - 계산 중 0으로 나누기 등으로 생긴 값은 계산 불가로 보고 해당 날짜 결과에서 제외
          (inf나 0점으로 저장하지 않음)

  출력① indicator_scores → indicator_score 테이블
        code, as_of_date, rule_version, stress_value, percentile, score
        - 변환값이 있는 날짜마다 한 행. 비교 기간 2년 미만이면 percentile·score NaN

  출력② daily_scores → daily_scores 테이블
        as_of_date, rule_version, equity_score, fx_score, rate_score, credit_score,
        total_score, total_percentile, stage, spread_count, is_provisional
        - 5개 지표 점수가 모두 있는 날짜만 (결정 2-A)
        - 종합 비교 기간 2년 미만이면 total_percentile NaN, stage None
        - spread_count int, is_provisional 항상 False
  반올림하지 않습니다 (회신 #5). 표시 단계에서 반올림해 주세요.

  NaN 처리: percentile, score, total_percentile은 float NaN, stage는 None (계약 5-2·5-3대로).
    run.py의 _rows()가 NaN → None(NULL)으로 바꾸므로 추가 작업 불필요 (위 ★ 확인).
    run.py 외의 경로(예: API에서 DataFrame을 직접 JSON으로 만들 때)에서는 같은 변환이 필요함
    (NaN은 표준 JSON이 아니고, psycopg는 NaN을 NULL이 아닌 'NaN'으로 저장).
    - 참고: API 규격의 /scores/latest stage는 string(null 불가)입니다. 최신 기준일에는
      항상 stage가 있으므로 문제는 없지만, /scores 기간 조회에서는 2021-10 이전 stage가 null입니다.

8. 알려진 문제 · 예정
======================================================================
  - 엑셀 독립 계산 대조는 10/15 추가 예정 (현재 기대값은 Python 독립 계산)
  - 회신 추가 확인 사항(#4 해석 문장, #5 반올림 위치, #6 계산 불가 기간, #7 Python 버전)
    답변에 따라 수정될 수 있음
  - 같은 값 판정: 상대 오차 1e-12 이내는 같은 값으로 셈 (부동소수점 끝자리 오차 보정).
    엑셀 등으로 검산할 때는 변환값을 소수 10자리로 ROUND한 뒤 비교해야 결과가 일치함.
  - 중간순위 특성상 백분위 최댓값은 100에 가깝지만 100이 되지 않음 (예: 2,500개 중 최댓값 → 99.98).
    따라서 지표 점수 최댓값도 25에 가깝지만 정확히 25는 되지 않음.
  - 최소 기간 조건은 '첫 유효 값'만 봄 (회신 1-A 규칙). DB에 수년 단위 공백이 생기면
    10년 창 안의 값이 적어도 백분위를 계산함 → 실제 FRED 데이터에는 해당 없음, 방법론 한계로 기재
  - API 키·DB 접속 정보 사용하지 않음 (파일에 비밀값 없음)
