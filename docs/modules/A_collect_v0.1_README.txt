A 모듈 (수집·DB) 전달본 v0.1
================================
작성: A (송수원) · 대상: C (통합) · 기준 문서: 시스템 운영·모듈 전달 가이드 v1.0

1. 파일 구성 (저장소 경로 그대로)
--------------------------------
pipeline/collect.py      fetch_observations(), SERIES          ← 가이드 4-1
pipeline/db.py           get_connection(), upsert_observations(),
                         load_observations()                   ← 가이드 4-2
db/schema.sql            5개 테이블 + 지표 5개 초기 입력        ← 가이드 4-3 (C 초안 검토본)
tools/a_check.py         (보조) FRED 실측: 시작일·결측·공개 지연 + B용 CSV 생성
tools/a_initial_load.py  (보조) B 산식 없이 원본만 초기 적재 (C와 합의 후 실행)
A_check_report.txt       (첨부) 실측 결과
A_sample_observations.csv(첨부) 수집 결과 샘플 (code, obs_date, value)

※ tools/ 는 운영 파이프라인에 필요 없는 보조 스크립트. 저장소에 넣을지는 C 판단.

2. 계약 준수 사항
--------------------------------
[collect.py]
- 출력 컬럼: code(str), obs_date(datetime.date), value(float 또는 None)
- FRED "." → None (0으로 바꾸지 않음). (code, obs_date) 중복 제거, code·날짜 오름차순
- API 키는 환경변수 FRED_API_KEY에서만 읽음. 없으면 RuntimeError
- 지표 하나라도 실패하면 RuntimeError 발생 (일부만 받고 넘어가지 않음)
  · 400/401/403/404(코드·키 오류)는 즉시 실패
  · 네트워크 오류·429·5xx는 3회까지 재시도 후 실패
- start/end 형식(YYYY-MM-DD) 확인, end=None이면 오늘까지

[db.py]
- get_connection(): DATABASE_URL로 psycopg 연결. prepare_threshold=None 설정
  (Supabase pooler 사용 시 prepared statement 충돌 방지)
- upsert_observations(): (code, obs_date) 기준 INSERT ... ON CONFLICT DO UPDATE.
  fetched_at = 저장 시각(UTC). NaN/None → NULL. 반환값 = 저장 행 수.
  ★ commit 하지 않음 (run.py가 확정)
- load_observations(start=None): code, obs_date, value 반환.
  value는 float64 (NULL → NaN). DB numeric이 Decimal로 읽히는 것을 float로 변환함.
- 데이터 삭제 함수는 두지 않음 (S&P500 과거 데이터 보존 원칙)

[schema.sql]
- C 초안을 그대로 유지. 변경 2건:
  + CREATE INDEX IF NOT EXISTS observations_obs_date_idx ON observations (obs_date);
  + 5개 테이블 ENABLE ROW LEVEL SECURITY
    (Supabase 자동 공개 REST API로 외부에서 읽고 쓰는 것을 차단.
     DATABASE_URL의 postgres 계정은 테이블 소유자라 영향 없음 — 로컬에서 확인)
- DROP/DELETE/TRUNCATE 없음. 여러 번 실행해도 오류 없음 (확인함)

3. 실행 방법 (macOS 기준)
--------------------------------
  cd team7-stress-dashboard            # 저장소 루트
  python3 -m venv .venv && source .venv/bin/activate
  pip install -r requirements.txt      # pandas, requests, psycopg[binary] 사용
  export FRED_API_KEY="본인키"
  export DATABASE_URL="C가 안내한 주소"

  python -m pipeline.collect --start 2026-09-01     # DB 없이 수집만 확인
  python -m tools.a_check                           # 실측 리포트 + B용 CSV
  python -m tools.a_initial_load --codes VIXCLS --start 2026-09-01   # 1개 지표 저장 시험
  python -m tools.a_initial_load                    # 전체 초기 적재 (2005-01-01~)

  Windows PowerShell은 export 대신:  $env:FRED_API_KEY = "본인키"

추가 라이브러리: 없음 (requirements.txt 범위 안)

6. 알려진 사항 / C 확인 요청

- run.py의 --days 14 재수집은 FRED 기준 '관측일' 14일. DEXKOUS 공개 지연(약 1주)보다 길어 문제 없음
